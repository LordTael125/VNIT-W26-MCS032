1. Hands-On: Simple Shell Script

Q. Take a simple shell script from ChatGPT, run it, find where it fails, and validate it.

Ans: I tested a simple shell script for counting files in a directory. It worked correctly for normal files, but hidden files and symbolic links needed separate testing. I checked the commands used in the script and compared the actual output with the expected output. This helped me understand that a script generated by ChatGPT should be tested under different conditions before trusting it.

2. Process Counter – What I Validated

Q. What did you validate in your process-counting script?

Ans:
I created and executed process_report.sh to count the processes running for my current user. During testing, the script reported 95 processes for my user at that time. The result was saved in process_report.txt, and I verified the file using the cat command. I also observed that the process count can change when applications are opened or closed.

Limitation:
The script only counts processes belonging to the current user. It does not count processes belonging to all users on the system.

Ans:
The man command was the most surprising for me because it provides detailed documentation directly in the Linux terminal. It helped me understand that I can check how a command works without depending completely on external websites.

Q2. If ChatGPT gave you a script, what would you still need to check before trusting it?

Ans:
I would run the script and compare its output with the expected result. I would also test different conditions such as hidden files, empty directories, symbolic links, invalid input, and permission problems. I would check the manual pages of the commands used in the script as well.
